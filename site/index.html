Marco

A voice-and-vision browser assistant, built on Google's open-weights Gemma 4. Reads your tabs, shows you where to click, verifies its own answers, and runs passive cybersecurity checks.

What it does

One agent per tab

Every tab gets its own Gemma 4 agent with its own memory, so your GitHub repo, docs and dashboard never get mixed up. Agents can even ask each other questions.

Show me

Ask "how do I sign up?" and Marco scrolls to the right button and draws a glowing ring on it — not just a text answer.

Answers you can verify

Facts come with citation pins. Click one and the exact sentence it came from is highlighted on the page. Unverifiable citations are silently dropped.

Security scan

Passive checks for missing headers, exposed files, outdated libraries, weak tokens and open redirects — each with a concrete fix.

Defacement monitoring

Save a baseline of a page, then ask anytime "has this been hacked?" A background sweep can also check on its own and notify you.

Reflected-input testing

Checks whether a site's search box or query parameters reflect input unsafely — using a harmless marker, never a real script — gated behind an allowlist and a confirmation every time.

WHOIS / domain info

Who registered a domain and when, straight from public RDAP and DNS records — no connection to the site itself.

Hindi, English, Hinglish, Gujarati

Speaks naturally in the language you use, and only out loud when you actually asked by voice.

Try it in under 2 minutes

  1. Clone the repo: git clone https://github.com/hackelite01/MARCO-Extension.git
  2. Follow the Setup section of the README: install the Python bridge, add your Gemini API key, start the bridge.
  3. Load the extension/ folder as an unpacked extension at chrome://extensions or edge://extensions.
  4. Open the side panel, connect, and start talking.
